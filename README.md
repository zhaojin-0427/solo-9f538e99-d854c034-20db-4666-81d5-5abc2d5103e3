# 封闭池塘标记重捕估算系统

第二轮调查有些鱼的标记号看不清：先按两轮独立抽样估出鱼数范围，再决定要不要补查。
Flask + SQLite 单页应用，支持 `docker compose` 一键启动，附独立离线复算脚本。

## 功能

- **上传两轮 CSV**（各 1～300 条）：
  - 首轮：表头 `tag`，每行一个放回鱼的**唯一标记号**；
  - 次轮：表头 `sample_no,status,candidates`，每行填唯一样本号、标记状态
    （`有标` / `无标` / `看不清`）和来自首轮的候选标记号（`;` 分隔，可空）。
  - 两轮都可再加**体长列**，见下节。
- **配对规则**：有标必配、无标不配、看不清可配可不配、每个首轮标记只用一次。
  用二分图匹配（Hopcroft-Karp）求：
  - **最少重捕数** = 覆盖全部有标样本的匹配（附一套配对）；
  - **最多重捕数** = 在此基础上让"看不清"样本尽量增广（附一套配对）。
- **鱼数估算**：`N = 首轮条数 × 次轮条数 ÷ 重捕数`，按最少/最多重捕给出估算两端；
  重捕数为 0 的端点标为**不可估**。体长数据不参与鱼数估算。
- **逐条更正**：网页上每条次轮记录带**版号**，按所见版号提交更正（乐观锁），
  成功当次显示并保存新估算，版号 +1。体长可按毫米更正，或**留空清空**。
- **无解证明**：若无法覆盖全部有标样本，按霍尔定理给出一组有标样本及其候选号并集。
- **失败保护**：过期（版号不符）、格式有误、无解或写入失败时，本次修改不生效，
  上次记录与估算原样保留；数据存于 SQLite 文件，**重启后仍可查看**。

## 体长对照

### CSV 体长列

两轮 CSV 各自**可以**加一列体长：

- `length_mm`：正整数毫米；
- `length_cm`：十进制厘米，必须能**精确**换成正整数毫米（如 `16.8` → 168）。

规则：

- 同一份 CSV 里两个列**并存即整份拒收**；留空或无此列算**未测**。
- 非空值无法精确换成正整数毫米（`10.25` cm、`10.5` mm、`-3`、`0` 等）时**整份拒收**，
  旧数据与快照不受影响。
- 只有两轮**全部实测**时才做累计比例比较；任一轮有缺测时，只显示各轮缺测数。

### 比较结果

首页点“比较体长”（`GET /compare`），使用同一已提交调查的两轮记录：

1. 按实测体长求两轮累计比例（体长不超过 x 的条数 ÷ 该轮样本数）的**最大绝对差**，
   列出该体长（并列取最小）、两轮比例与差值，均以精确分数显示。
2. 保持各轮样本数，给出**所有等可能重分组**中“最大绝对差不小于实测值”的比例，
   以精确分数显示。等长记录各计一条，只有整组等长记录都安排完才比较；
   组合数用动态规划计算（最多 600 个位置），不逐套枚举。

### 快照与下载

每次上传或更正若改变了毫米读数，就归档为一次“已提交调查”，页面上有编号：

- `/lengths/current.json`：当前调查的两轮毫米读数；`/lengths/<编号>.json`：指定调查；
- 缺测写 `null`；`n1` / `n2` 为各轮样本数；
- 更正或整份重传只会新增快照，**旧编号的 JSON 始终可下载**（旧页上的链接继续有效）；
  整份重传时相同样本号也只取新数据。

### 离线复算脚本

`recompute.py` 只依赖 Python 标准库，不读数据库、不导入 Flask：

```bash
python recompute.py lengths-1.json
```

输出与结果页各项一一对应：缺测时只报各轮缺测数，数据齐时给出体长、两轮比例、
差值、绝对差与重分组比例的精确分数。无效文件只打印一行错误并以非零状态退出。

## 启动

### Docker Compose（推荐）

```bash
docker compose up --build
```

访问 http://localhost:8000 。SQLite 数据库保存在命名卷 `appdata` 中，容器重建不丢数据。
容器内经 gunicorn 启动；离线脚本在镜像内也可用
`docker compose exec web python recompute.py /data/lengths-1.json`。

### 本地运行

```bash
pip install -r requirements.txt
python app.py            # 默认 0.0.0.0:8000，DB 为 ./markrecap.db
```

环境变量：`DB_PATH`（数据库路径）、`PORT`（端口）、`SECRET_KEY`（会话密钥）。
旧版数据库在启动时自动补齐体长列。

## CSV 示例

`examples/round1.csv`：

```csv
tag,length_mm
T01,152
T02,168
```

`examples/round2.csv`：

```csv
sample_no,status,candidates,length_cm
s01,有标,T01,15.2
s02,有标,T02;T03,16.8
s07,无标,,13.9
s13,看不清,T10;T11,15.8
```

- 编码 UTF-8（可带 BOM）；候选号可用 `;` `；` `|` `/` `、` `,` 或空格分隔。
- 表头支持中文别名：`标记号` / `样本号` / `状态` / `候选号`。
- 候选号必须来自首轮；`无标` 行不得填写候选号。
